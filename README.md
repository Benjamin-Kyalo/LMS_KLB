# Research deliverables

This folder contains the strategic research and concept report for a proposed Kenyan digital learning ecosystem.

| File | Purpose |
|---|---|
| `Kenyan_Digital_Learning_Ecosystem_Strategy_Report.docx` | **Presentable Word version** — styled title page, contents, headings, tables, clickable links and page numbers. Use this for sharing and review. |
| `Kenyan_Digital_Learning_Ecosystem_Strategy_Report.md` | The complete report in Markdown — the source file, organised in the requested 21-section order, with comparison matrices and user journeys. |
| `README.md` | This index. |

## How to read the report

- The report labels evidence throughout: **[Verified]** (official/primary source), **[Claim]** (vendor self-description), **[Secondary]** (credible third party), **[Assumption]** (inference), **[Recommendation]** (our proposal).
- Every statistic carries a source link and date. Conflicting figures are shown as conflicts, not silently resolved.
- This report was originally research and strategy only. A subsequent working
  implementation now exists in `kenyan-lms/`; see its `README.md` and
  `docs/HANDOVER_REPORT.md` for the current build status.
- Research cut-off: **23 November 2026**.

## Scope note

Five reference platforms were studied as sources of ideas, not as templates to copy: Zeraki (Kenya), ShuleSoft (Tanzania), Moodle (international), Canvas LMS (international) and Eneza Education (Kenya/Africa). The report deliberately evaluates them on their own terms rather than forcing them into one category.
